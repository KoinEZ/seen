# Русификатор Seen [Недоделан]

Взял [маленькую игру](https://store.steampowered.com/app/1069740/Seen) попробовать вскрыть Unreal 4, получилось перевести только часть. Перевод отложен до расширения технических возможностей по внедрению файлов в закодированную часть. Если вам он зачем-то нужен, то:

[`Seen-RU-v0.7.zip`](Seen-RU-v0.7.zip)
Установка:

- Скачать архив
- Запустить батник install.bat

или

- Найдите папку игры: Steam -> ПКМ по Seen -> Свойства -> Установленные файлы -> Обзор... (откроется папка игры, нужна подпапка MG3\Content\Paks)
- Положите в неё (Paks) файлы из архива с заменой
